# See dbsp in Action

Watch a live session using the dbsp REPL. Commands are compiled to SQL instantly — no database needed.

<TerminalDemo />

## What you just saw

- **NQL pipe syntax** — readable query language compiled to optimized SQL
- **Automatic JOIN strategy** — the planner chose `lateral-join` for the to-one author relation
- **Full observability** — every query shows its SQL, parameters, and plan decisions
- **Zero setup** — the REPL works in compile-only mode, no database connection required
